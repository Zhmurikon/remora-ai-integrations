# Remora AI Integrations

Инструменты для подключения внешних агентов (Claude, GPT и других MCP-совместимых клиентов)
к [Remora](https://remora.com.ru/) — платформе для заучивания через карточки.

Репозиторий содержит два независимых компонента:

- [`mcp-server/`](mcp-server) — MCP-коннектор к агентскому JSON API Remora: список инструментов
  для чтения и записи наборов карточек и курсов.
- [`skills/remora-author/`](skills/remora-author) — навык (skill) для агента: как превращать
  присланные пользователем источники в качественные карточки и курсы, с проверкой форматов
  и правилами безопасной публикации.

Оба используют один и тот же контракт агентского API Remora и предназначены для совместного
подключения: skill объясняет агенту, *как* писать материалы, MCP-сервер — это инструмент,
*которым* он это делает.

## Быстрый старт

1. В кабинете Remora откройте «Настройки → API и ИИ-агенты» и создайте персональный токен
   с нужными правами (`materials:read`, `materials:write`, при необходимости `courses:publish`).
   Секрет показывается только один раз — сохраните его в защищённом хранилище.
2. Установите MCP-сервер и настройте ваш MCP-клиент на его запуск (см.
   [mcp-server/README](#mcp-server)).
3. Подключите папку [`skills/remora-author`](skills/remora-author) как skill в вашем агенте.

## MCP-сервер

Локальный stdio-коннектор. Вся авторизация и бизнес-логика остаются на стороне JSON API —
сервер не хранит данные и не обращается к базе напрямую.

```bash
cd mcp-server
uv sync
```

Настройте MCP-клиент на запуск:

```text
command: uv
args: [run, --directory, /absolute/path/to/remora-ai-integrations/mcp-server, remora-mcp]
environment:
  REMORA_API_URL: https://remora.com.ru
  REMORA_API_TOKEN: <значение из защищённого хранилища>
```

Локально для разработки допустим `REMORA_API_URL: http://localhost:8000`; вне localhost
обязателен HTTPS. Никогда не передавайте токен в аргументах командной строки, документации
или коммитах.

Доступно 16 инструментов: чтение/создание/обновление наборов и курсов, публикация/снятие
с публикации, чтение и изменение структуры курса без перезаписи карточек, копирование курса
или отдельной статьи, явное удаление статьи или раздела, безопасная загрузка изображений.
Полный контракт запросов и ответов — в [`skills/remora-author/references/api.md`](skills/remora-author/references/api.md).

Проверки:

```bash
cd mcp-server
uv run ruff check .
uv run mypy src
uv run pytest
```

## Skill: remora-author

Самодостаточный навык для агента: как читать присланные источники, строить структуру курса,
писать карточки и правдоподобные неверные ответы в обоих направлениях, работать с изображениями
и когда допустима публикация. Подробности — в [`skills/remora-author/SKILL.md`](skills/remora-author/SKILL.md).

Навык не требует доступа к этому репозиторию во время работы — справочники внутри него
самодостаточны и включают проверяемый пример входного курса.

## Совместимость

Оба компонента реализуют контракт агентского API Remora независимо от версии основного
приложения. При изменении контракта (`/agent/*`) обновления публикуются здесь отдельными
коммитами/релизами.
