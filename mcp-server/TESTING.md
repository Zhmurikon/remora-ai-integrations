# Проверка MCP

## Автономные проверки

Из каталога `mcp-server`:

```bash
uv sync --frozen
uv run ruff check .
uv run mypy src
uv run pytest -q
```

Без внешнего API выполняются 108 тестов; один сквозной тест пропускается.
Сервер запускается через stdio в `test_server.py`, остальные тесты используют MCP-диспетчер
с управляемым HTTP-транспортом и прямую проверку схем.

## Сквозной тест

`test_live_api.py` проверяет настоящий stdio → HTTP → API → БД/S3. Нужен отдельно запущенный
локальный API Remora с **выделенными тестовыми** PostgreSQL, Redis, MailHog и MinIO.
На пустой тестовой БД сначала выполнить `uv run alembic upgrade head` из `apps/api` Remora.
API должен использовать те же тестовые DATABASE_URL/REDIS_URL, локальный SMTP и отдельный
S3_ENDPOINT с существующим приватным бакетом `remora-media`. Обязательны настройки SMTP
без рабочих логина/пароля и без STARTTLS для MailHog. Не запускать worker для этого теста.

```bash
REMORA_TEST_API_URL=http://127.0.0.1:18000 uv run pytest tests/test_live_api.py -q
```

Допускается только localhost/127.0.0.1. Тест сам создаёт технический аккаунт и PAT, не читает
рабочий REMORA_API_TOKEN и отзывает выданные токены в finally. Материалы/аккаунт остаются
в тестовой БД до удаления стенда. Не направлять тест на локальный прокси рабочего API.

## Матрица сценариев

| Сценарий | Ожидаемый результат | Покрытие |
| --- | --- | --- |
| Инициализация, список инструментов | 16 инструментов и инструкции | stdio |
| Каждый из 16 инструментов | Правильные метод, URL, авторизация, ключ записи | transport + live |
| Создание набора | Сохраняются карточки; visibility=public; публичное чтение 200 | live |
| Создание курса | Курс не опубликован, вложенные наборы публичны | live |
| Идентичный повтор записи | Тот же ID, без дубликата | live |
| Тот же ключ, другое содержимое | 409 | live |
| Изменение набора/полного курса | Прежние ID карточек, актуальная revision | live |
| Изменение только структуры | Карточки не изменяются; stale revision → 409 | live |
| Публикация | is_published=true, публичный GET 200; повтор идемпотентен | live |
| Редактирование опубликованного курса | 409, публикация не снимается автоматически | live |
| Публикация пустого курса | 409 с понятной причиной | live |
| Публикация без scope | 403 с required_scope=courses:publish | live |
| Снятие публикации | Курс 404 публично; вложенный набор остаётся public | live |
| Независимая копия | Новые ID карточек и изображений; курс не опубликован | live |
| Удаление статьи/раздела | Исчезает теория; связанный набор/карточки сохраняются | live |
| SVG → загрузка → статья → копия | Реальное S3, metadata/markdown_reference, идемпотентность | live |
| Неверный base64 | 409 с объяснением API | live |
| 401/402/403/404/409/422/429/500 | Сохраняются код и разрешённые детали; PAT/input/ctx не раскрываются | transport |
| Редирект API | Не выполняется второй HTTP-запрос | transport |
| Таймаут/невалидный JSON | Понятная ошибка, результат неизвестен, сохраняется request_key | transport |
| Ошибочный origin/token | Ошибка конфигурации до HTTP | configuration |
| Неверные limit/offset/request_key | Ошибка MCP до HTTP | transport |
| Неизвестные поля, опечатки | Отклоняются, не теряются молча | transport |
| Границы полей/массивов/суммарного объёма | Допустимые размеры принимаются, превышение отклоняется | schemas |
| Неверные ответы совпадают с правильными/синонимами | Отклоняются, учитываются ё/е, пробелы и регистр | schemas |
| Пример курса в навыке | Валиден относительно схемы | schemas |
| `<package>`, `<T>`, HTML в text/latex, включая backticks | Отклоняются до HTTP с путём до карточки | schemas + transport |
| Те же примеры в code с языком | Сохраняются буквально; отсутствие языка отклоняется | schemas + stdio |
| Кириллица/ё/эмодзи/иероглифы через stdio | Точное равенство полей, включая PYTHONIOENCODING=cp1251 | stdio |


Права владельца, отзыв/срок токена, атомарность транзакций, гонки, SSRF и публикация каждого
вложенного набора дополнительно проверяются в репозитории Remora:
`tests/test_agent_api.py`, `test_agent_e6b.py`, `test_agent_media.py`,
`test_course_publication.py`, `test_course_editor.py`, `test_article_media.py`, `test_svg.py`.
`test_agent_content_format.py` воспроизводит отказ HTML-подобного плейсхолдера в целом курсе,
атомарный откат и восстановление через code, а также Unicode/JSON escapes до публичного чтения.
Не подменять эти проверки HTTP-заглушкой коннектора.

Инструкции MCP и навыка задают требования к качеству учебного содержания. Проверка схемы
не проверяет истинность фактов, качество источников и педагогическую полноту.
